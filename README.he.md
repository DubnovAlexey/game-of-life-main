# Game of Life

[English](README.md) · **עברית** · [Русский](README.ru.md)

ההתחלה של "משחק החיים" של קונוויי בדפדפן: לוח של 30 × 20 שבו לחיצה מחיה תא. השלב הבא הוא הסימולציה עצמה.

**הדגמה חיה:** https://dubnovalexey.github.io/game-of-life-main/

## יכולות

- הלוח נבנה ב-JavaScript כ-CSS Grid של 30 × 20 תאים.
- לחיצה מחליפה תא בין חי למת.
- מטפל לחיצה אחד לכל הלוח (event delegation) במקום 600 מטפלים נפרדים.
- התאים החיים נשמרים ב-`Set` עם מפתחות `"row_col"`, ולכן הוספה, מחיקה ובדיקה של תא מיידיות.

## טכנולוגיות

HTML5 · CSS Grid · JavaScript (DOM, `Set`, event delegation) · GitHub Pages

## מה תרגלתי

- בניית רשת מתוך נתונים במקום מאות אלמנטי `div` ידניים.
- event delegation ומאפייני `data-*`.
- בחירת מבנה נתונים (`Set`) לחיפוש מהיר.

## הרצה מקומית

פתחו את `index.html` בדפדפן.

## תוכניות

- סימולציה לפי חוקי קונוויי: תא מת עם שלושה שכנים חיים נולד, תא חי עם שניים או שלושה שכנים שורד.
- כפתורי התחלה, עצירה, צעד, אקראי ומהירות.
- לוח גדול עם חישוב ב-Rust שמהודר ל-WebAssembly, כמו בפרויקט UNIVERSE שלי.

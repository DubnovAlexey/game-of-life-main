# Game of Life

**English** · [עברית](README.he.md) · [Русский](README.ru.md)

The start of Conway's Game of Life in the browser: a 30 × 20 field where you click cells to bring them to life. The next step is the simulation itself.

**Live demo:** https://dubnovalexey.github.io/game-of-life-main/

## Features

- The field is generated by JavaScript as a CSS Grid of 30 × 20 cells.
- A click toggles a cell between alive and dead.
- One click handler on the whole field (event delegation) instead of 600 separate handlers.
- Live cells are kept in a `Set` of `"row_col"` keys, so adding, removing and checking a cell are instant.

## Tech stack

HTML5 · CSS Grid · JavaScript (DOM, `Set`, event delegation) · GitHub Pages

## What I practised

- Building a grid from data instead of writing hundreds of `div` elements by hand.
- Event delegation and `data-*` attributes.
- Choosing a data structure (`Set`) for fast lookups.

## Run locally

Open `index.html` in a browser.

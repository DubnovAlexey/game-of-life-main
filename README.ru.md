# Game of Life

[English](README.md) · [עברית](README.he.md) · **Русский**

Начало игры «Жизнь» Конвея в браузере: поле 30 × 20, где щелчком можно оживить клетку. Следующий шаг — сама симуляция.

**Демо:** https://dubnovalexey.github.io/game-of-life-main/

## Возможности

- Поле строит JavaScript: CSS Grid из 30 × 20 клеток.
- Щелчок переключает клетку между «живая» и «мёртвая».
- Один обработчик щелчков на всё поле (делегирование событий) вместо 600 отдельных.
- Живые клетки хранятся в `Set` с ключами `"строка_столбец"`, поэтому добавление, удаление и проверка клетки мгновенные.

## Технологии

HTML5 · CSS Grid · JavaScript (DOM, `Set`, делегирование событий) · GitHub Pages

## Что я отработал

- Построение сетки из данных, а не сотнями `div` вручную.
- Делегирование событий и атрибуты `data-*`.
- Выбор структуры данных (`Set`) для быстрого поиска.

## Запуск

Откройте `index.html` в браузере.

## Планы

- Симуляция по правилам Конвея: мёртвая клетка с тремя живыми соседями рождается, живая с двумя или тремя выживает.
- Кнопки «Старт», «Стоп», «Шаг», «Случайно» и «Скорость».
- Большое поле с расчётом на Rust, собранном в WebAssembly, — тот же подход, что в моём проекте UNIVERSE.
